# Buyer Notes — EntropyMint

**What you get**
- Complete offline Python CLI (`entropymint.py`)
- Health tests that verify generation and scoring
- README with usage examples
- MIT license

**How to run**
```bash
python3 src/entropymint.py generate --length 32 --json
python3 src/entropymint.py score "your-secret-here"
python3 src/entropymint.py health
```

**Requirements**
Python 3.9+. No pip installs required. Works fully offline.
